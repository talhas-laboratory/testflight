# Concept Lab workspace

## Mission

Maintain source-anchored conceptual exploration, theory branches, formation proposals, and reverse
traces without confusing them with accepted Product state or runtime execution.

## Routing

- Use the smallest named child domain first. An in-domain child `NO_HITS` never broadens to a
  parent-wide search.
- The `relational-content/` child owns the first proof domain. It is structurally valid but has no
  imported source records in this task.
- `AGENT_INDEX.md` and `AGENT_CONFIG.yaml` are navigation and policy material, not ordinary
  domain answers.
- Product exchange is unavailable until an explicit bridge is registered. Workspace registration
  alone is not traversal permission.

## Canonical artifacts

- `WORKSPACE.yaml`: sovereign identity, topology, authority, and lifecycle.
- `AGENT_CONFIG.yaml`: retrieval and quality policy.
- `artifacts/source_manifest.yaml`: parent-owned canonical source manifest.
- `artifacts/child-registration-receipt.yaml`: child construction and validation receipt.
- `resource_registry.json`: parent resource metadata.
