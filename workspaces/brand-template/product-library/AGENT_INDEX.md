# Product library

This reusable child routes `product-index`, `product-knowledge-space`, `product-image-space`,
`product-purpose-space`, and `product-end-user-connection-space`. Resolve a stable product UID
first. Use exact/BM25 retrieval inside the selected route and return `NO_HITS` where no approved
record exists. Never treat metadata alone as sufficient for exact generated product likeness.
