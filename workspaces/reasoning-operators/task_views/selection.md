# Selection task view

## Goal

Choose the smallest guardrail operator that can prevent the current mistake.

## Procedure

1. State the task, locus, goal, requested output, and stakes.
2. Classify the failure category; do not jump from a symptom to a fix.
3. Read only the selected operator and its canonical source references.
4. Add a second operator only when a declared precondition or evaluator
   requires it.
5. Compile the operator-local packet with evidence, authority, scope, time,
   relations, conflicts, uncertainty, permissions, and invariants.

The selection result is a route proposal, not a semantic conclusion.
