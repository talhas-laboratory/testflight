# Evaluation task view

## Goal

Prove that an operator result is structurally valid, invariant-compliant,
semantically grounded, and useful for the requested task.

## Procedure

1. Validate the schema and source references.
2. Validate scope, authority, branch, uncertainty, and operator invariants.
3. Run the operator's semantic rubric or held-out fixture.
4. Evaluate downstream utility without letting utility erase provenance.
5. Report each dimension separately; a schema pass is not a semantic pass.

Failure, insufficient context, and no-hit results remain inspectable and are
not normalized into acceptance.
