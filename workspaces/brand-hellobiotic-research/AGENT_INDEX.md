# Agent index

Route public evidence by task view: research → source catalog/evidence; entity → entity/context records; relationship → relationship inventory; asset-context → workflow context; visual-language → visual module; product-library → stable product identity, approved product assets, and product-context links.

Route founder-directed editorial strategy, relational content relevance, and newsletter-agent
generation rules to `content-strategy/AGENT_INDEX.md`. This child is isolated from the default
public-research corpus; its strategic hypotheses are not customer or scientific evidence.

For the Brand World v3 migration, start at `v3/README.md`. The files in `v3/` are a deterministic,
proposal-only review bundle: `proposed-public-research-branch.json` is the compiler fixture,
`migration-integrity-report.json` is the semantic gate, and `authority-review-proposal.json` is the
explicit route toward `client-approved-v3`. No file in that directory is an accepted client record.
