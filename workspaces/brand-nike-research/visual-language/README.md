# Nike visual language

This is a proposal-only, public-research visual-language pack. It does not claim to reproduce
Nike's confidential design system. References are deliberately modular so a future authorized
source can add colors, typography, layout, motion, accessibility, or production components without
rewriting profile history.

The manifest separates:

- `references`: reusable modules;
- `revisions`: immutable collections of modules;
- `bindings`: the context and time in which a revision applies;
- `gaps`: requested visual details that public research does not establish.

Audience segments are selectors inside the Nike world, not separate tenants. A profile can be
applied to several compatible audience segments, but a segment-specific overlay must never be
treated as universal Nike language.
