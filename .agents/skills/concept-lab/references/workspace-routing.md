# Workspace routing

Start at `workspaces/concept-lab/AGENT_INDEX.md`, then the smallest named child. The initial child is `relational-content`; it is unpopulated until a scoped source record or bridge packet exists. Use exact lookup or BM25 first. Do not broaden a child no-hit to its parent.

The Product bridge accepts explicit packet source refs only and has traversal disabled. Read `workspaces/concept-lab/artifacts/testflight-product-bridge.yaml` only for an authorized packet exchange or target route.
