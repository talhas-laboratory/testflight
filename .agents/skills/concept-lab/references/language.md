# Shared language

Keep source material, interpretation, theory branch, formal proposal, technical projection, accepted Product state, and runtime execution distinct. A ConceptFragment is a source-anchored candidate meaning; a TheoryBranch is coherent but unaccepted; a FormationPacket is a proposed technical projection; a ReverseTrace reports lineage and missing links.

Compose existing Evidence, Context, WorldBranch, Derivation, AuthorityGrant, ContentUnit, KnowledgeContainer, and FederationBridge references rather than redefining them.
