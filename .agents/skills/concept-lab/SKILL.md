# Concept Lab

Use the Lab as a bounded formation practice, not a persistent mode or a store of truth. Select and state one mode: `explore`, `distill`, `formalize`, `form`, or `trace`. Read [language](references/language.md) first, then only the mode and routing reference needed.

Route to the smallest named Concept Lab child. A child no-hit stays a no-hit. Product material may enter only through an explicit packet; a FormationPacket always has `canonical_write: false` and requires human promotion in its target workspace.

Return `branch`, `ask`, `hold`, `partial`, or `no_hit` when source lineage, authority, scope, target identity, or trace continuity is insufficient. Do not turn a founder theory into a customer fact, scientific claim, accepted Product state, or runtime instruction.

Use [modes](references/modes.md), [workspace routing](references/workspace-routing.md), and [formation targets](references/formation-targets.md) progressively.
