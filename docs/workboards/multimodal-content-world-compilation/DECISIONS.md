# Decisions

Record durable decisions here.

## 2026-09-04 — Treat Content as a substrate, not a second World

The implementation will preserve raw evidence, observation, normalized Content, interpretation,
module knowledge, World proposals, accepted World state, retrieval, reasoning steering, and action
as distinct semantic planes. ADR 0006 is the controlling decision for the new extension.

## 2026-09-04 — Certify contracts against a provider-free three-reel corpus

The first Content contracts will be driven by a synthetic three-reel profile containing two
independent supporting occurrences, one counterexample, one unavailable modality, and explicit
hold/partial/no-hit cases. Live acquisition and encoded-media processing cannot redefine the
semantic contracts established by this fixture without a versioned decision.
